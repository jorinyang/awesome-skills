# 家庭聚会型方案 · 内容风格规范

> 适用于：双方家长见面、迎亲家、家庭聚会定制旅行方案。受众是两家长辈，不是内部操作备忘录。

## 核心原则

**站在展示视角，不站操作视角。**

方案是给双方父母看的——让他们感到这是专门为他们精心准备的旅程，而不是地接/家属的工作备忘录。

## 禁止项（操作视角）

| ❌ 禁止 | 原因 | 替代表达 |
|---------|------|---------|
| "我的车"/"我带女方父母" | 第一人称暴露内部安排 | 不写分车细节，或用"专车""车辆安排" |
| "妹妹开车接站" | 暴露家属角色 | "专车接站" |
| "妹妹做地接导游" | 操作角色不应该出现在展示方案里 | 去掉，或写"全程有家人陪同" |
| "到我家吃饭" | 私密信息 | "温馨家宴" |
| "待确认"/"待安排" | 未完成感 | 去掉此行，或写"另行告知" |
| 内部备注（"双人间×2"） | 操作细节 | 改为"已安排好舒适双人间" |

## 允许项（展示视角）

| ✅ 表达 | 说明 |
|---------|------|
| "欢迎来到兴义" / "专车接站" | 欢迎感 |
| "一桌家常菜，两家人第一次坐在一起" | 情感连接 |
| "兴义人最自豪的一碗粉" | 让食物有故事 |
| "全程坐船/坐车，不走路" | 关心长辈体力 |
| "一路平安，期待下次相聚" | 温暖的结尾 |

## 食谱写作规范

小吃介绍用"什么来头"而非"营养/成分"：

```
| 小吃 | 在哪天 | 什么来头 |
| 蛋炒饭 | D2 | 万峰林必吃，糟辣椒猪油炒，配泡萝卜 |
| 鸡肉汤圆 | D3 | 咸汤圆，鸡汤底，全贵州独一份 |
```

## 住宿写作规范

不写操作参数（房间数/楼层/朝向），写体验：

```
| 日期 | 酒店 | 体验 |
| 7/11 | 万峰林精品民宿 | 田园庭院，推窗即峰林 |
```

## 案例对比

### 修改前（操作视角）
> Day 2：分车出发。妹妹车带男方父母，我的车带女方父母。双人间×2，低楼层。

### 修改后（展示视角）
> Day 2：前往万峰林，约20分钟车程。入住田园庭院民宿，推窗即见峰林。

## 适用判断

当行程描述中出现以下信号时，自动切换到本规范：
- 关键词：亲家/双方家长/迎亲/家庭聚会/长辈见面
- trip.json 中 `group.type` = "私人定制" 且 `special_requests` 含"见面"/"家长"/"亲家"
- 用户明确说"给XX看的方案"而非"导游用的方案"
