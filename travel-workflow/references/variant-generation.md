# itinerary-variant — 行程变体生成模式

> 从已有基案（如 A类14天方案）派生命名变体（B/C/D方案），应用结构化变换规则。

## 触发条件

用户给出已有方案 + 明确的变换需求（删某天、改某天、压缩天数、注入新元素）→ 产出命名变体。

## 标准变换操作

| 操作 | 含义 | 示例 |
|------|------|------|
| **DELETE** | 删除指定天数 | `删除Day9-12` |
| **MODIFY** | 修改某天行程 | `Day6上午改桨板+竹筏，下午加犀牛洞` |
| **COMPRESS** | N天→M天（M<N），合并同类日 | `14天→7天` |
| **INJECT** | 注入新内容 | `完善每日午餐/晚餐` |
| **REDISTRIBUTE** | 重新分配晚间疗愈（部分天合并2项） | `Day2双熏蒸、Day5理疗+点筋` |

## 压缩规则（14→7天范式）

当从14天方案压缩为7天时：

1. **保留所有疗愈项目**，10项分布在7个晚间
   - 同类项目可合并：苗药熏蒸+中药熏蒸（同晚）、设备理疗+点筋调理（同晚）、两场讲座（同晚）
   - 每项目时长不压缩，总晚间疗愈时间通过合并自然消化
2. **远程景点优先删除**：贞丰（双乳峰/花江大桥，单程1.5-2h）、安龙（招堤，1h）、晴隆（二十四道拐，1.5h）
3. **核心景区保留**：万峰林、马岭河、万峰湖+吉隆堡、峰林布依（均在兴义周边1h内）
4. **纳具和园全日**至少保留2天：1天布依文化（扎染+糍粑+舞蹈）、1天深度疗愈（永生花+三合一理疗+讲座）
5. **Day6模式（水上+探洞一日）**：上午桨板+竹筏 → 中午岩架鱼 → 下午犀牛洞轻度探洞

## 餐饮注入规范

当用户要求完善餐饮，针对退休职工/中老年客群时：

### 口味约束
- 默认**少油少辣**，清蒸/清炖/白灼为主
- 保留风味但降辣度：酸汤→清汤底、辣子鸡→微辣版、蘸水提供不辣选项
- 不改变菜系本质，形式温和化

### 食材原则
- 每餐 **优质蛋白 + 时蔬 + 杂粮** 搭配
- 黔西南特色融入：薏仁米、黑山羊、岩架鱼、天麻、五色花米饭、折耳根、蕨菜、豌豆尖
- 晚餐偏清淡养胃：汤粥类、蒸菜、少煎炸

### 输出格式
每餐用 `<callout emoji="🍽️">` 块注明菜品 + 营养/风味说明。

## 命名约定

变体方案以大写字母命名：`A方案`（基案）→ `B方案`（中档）→ `C方案`（经济）→ `D方案`（精简疗愈）。

D方案的典型特征：7天、全保留疗愈、聚焦兴义周边、删除远程景点、餐饮详细标注。

## 输出格式

变体方案直接创建为飞书 docx，归档至知识库 → 业务记录 → 01-产品研发。

标题格式：`{路线名}{天数}{主题}（{方案代号}·{人数}人）`
示例：`黔西南7天康养疗愈深度体验路线（D方案·30人）`

## 与基案对照

变体方案末尾应包含对照表：
- 对比维度：天数、住宿、疗愈项目数、景区覆盖、轻户外、布依文化、远程景点、纳具全日、餐饮
- A类基案 vs 当前变体逐项对比
- 已删减内容明确标注 ❌
- 新增内容标注 ★
