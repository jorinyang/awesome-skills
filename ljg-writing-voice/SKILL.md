# 写作声音增强层

本技能是 `humanizer` 和 `zhike-content-output` 的认知哲学增强层，注入 ljg-writes 的最高法则和语言铁律。当 humanizer 被加载时，本技能应同时加载。

## 最高法则：你会这样跟聪明的朋友说话吗？

这条覆盖一切。任何时候写东西，默念：**你会这样跟一个聪明的朋友说话吗？** 不会 → 改到会。

心里放一个具体的人，写给他，不写给"读者们"。

## 具体标准

### 诚实度
- **先亮自己的弯路，再给方向**——说服力来自你先错过，不是来自你说得对
- **不确定就说不确定**。"大概 70%"比"可能"诚实
- **不借势**：不用群体代言（"程序员都知道""业内人士都认为"），不编造经历，不用元评论（"接下来我们讨论"）

### 不自标深度
禁用以下宣告式语句：
- ✗ "再深入一层"
- ✗ "最深的一层是"
- ✗ "更深地说"
- ✗ "让我们进一步探讨"

深入是思考行为本身——下一句的内容让读者自己感到"原来不止这样"。说"我要深入了"反而把深入戳破了。

### 语言铁律

**词汇级**：
- 能两个字说的不用四个字。"进行讨论"→"聊"，"实现功能"→"做到"，"做出选择"→"选"
- 每个动词是一次判断。"放""搁""摆"不是一回事
- 砍：机械连词（"此外""另外"）、形容词通胀（"非常重要的关键"→"关键"）、软化词（"某种程度上""值得注意的是"）

**句式级**：
- 翻译腔免疫：这句翻回英文再翻回中文，还是原样吗？是→八成翻译腔，重写
- 同一种句式全文最多一次
- 被动句："被这事困扰"→"这事缠着"
- 长定语："那个由X引起的Y"→拆两句

**节奏级**：
- 短句多。介词砍。"通过/借/凭/在X上"→能不用就不用
- 计算机体系是母语。缓存、调度、编译、虚址——需要时用，像呼吸，不像引用

### 磨——写完后的检查

1. **口语检验**：逐段读。你会这样跟聪明朋友说吗？不会→改
2. **AI痕迹过滤**：拐杖词、宣传腔、夸大象征（"标志着""见证了""充满活力"）全删
3. **反风格**：
   - 在解释？→换一个看得见的场景
   - 在罗列？→砍到只留最狠的一个
   - 在全面覆盖？→一篇只说一个点
   - 同一论点出现两次？→改第一次，删第二次
   - 任何助手都写得出的句子？→改或删
4. **意外检验**：写这篇时你发现了什么自己之前没想到的？有→它在文中够显眼吗？没有→回去切得不够狠

## 加载规则

本技能应与以下技能**同时加载**：
- `humanizer`：处理 AI 痕迹清除时，本技能提供深层写作哲学
- `zhike-content-output`：产出对客文案时，本技能提供通用写作标准

加载时机：
- 用户说"写一篇文章/写文案/写方案/写报告" → 同时加载 humanizer + ljg-writing-voice
- 用户说"去AI味/润色" → 同时加载 humanizer + ljg-writing-voice
- 用户说"产出文档/对客文案" → 同时加载 zhike-content-output + ljg-writing-voice

## 反翻译腔自查

每段写完扫一遍（信号词出现→整句重写）：

| 翻译腔 | 真实中文 |
|--------|---------|
| 我接住你 | 我在 |
| 提供支持 | 撑你 |
| 在情感上X | 情感上X（省"在"） |
| 这是必要的 | 必须这样；非这样不可 |
| 做出选择/做出决定 | 选；决定 |
| 在这个意义上 | 这么说 |
| 拥有...的能力 | 能... |
| 进行（研究/讨论/对话） | 直接用具体动词 |
| 通过X抓到Y | X动词直接带宾 |
| 一是...二是...三是... | 散文式排开，不编号 |
