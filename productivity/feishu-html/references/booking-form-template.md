# 报名表单页参考模板

## 概述
- 用途：作为对外 HTML 页面的「报名/咨询」落地页，承接所有「立即预订」按钮的跳转
- 文件名惯例：`{project}/book.html`
- OSS 路径：`web-spa/{slug}/book.html`
- 访问地址：`https://gzzhike.cn/web-spa/{slug}/book.html`

## 适用场景
当对外 HTML 页面（含「立即预订」等 CTA 按钮）需要报名表单时，从本模板派生，修改项目相关内容后部署。

## 结构规范

### 导航栏（简化）
- 左：品牌 Logo（贵州之客）→ 链接回首页
- 右/面包屑：当前页名称
- 不需要完整导航菜单（减少用户跳出）

### 表单字段（标准配置）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 姓名 | text | ✓ | maxlength=20 |
| 手机号 | tel | ✓ | 正则校验 /^1[3-9]\d{9}$/ |
| 体验项目 | radio | ✓ | 与主站价格方案对应（如三天两晚/单日体验/企业团建） |
| 计划出发日期 | date | | 默认填充 today+7 |
| 参与人数 | select | | 含 1人/2人/3-5人/6-10人/11-20人/20人以上 |
| 备注 | textarea | | placeholder 提示特殊需求 |

### 提交后行为
- 隐藏表单视图 → 显示成功视图（不要 alert，不要页面跳转）
- 成功视图内容：确认提交 + 引导添加客服微信 + 返回首页链接
- 原因：报名数据直接 POST 到后端（飞书多维表格 API 或企业微信机器人），用户提交后无需刷新页面

### 表单验证规则（必须实现）
- 姓名：非空
- 手机号：1[3-9]\d{9} 格式，不通过时在输入框下方显示红色提示
- 体验项目：默认选中第一项，不需要额外校验
- 日期：min=today（HTML date input 属性）

### 成功视图文案参考
```
预订咨询已提交
感谢你的信任，贵州之客客服将在 24 小时内通过微信/电话与你联系。

重要提醒：为更快得到确认，请搜索微信号 gzzhike2026 添加客服，备注「暑期预订」优先处理
```
