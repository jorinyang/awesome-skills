# 视频号冷启动策略

> **配套技能**：`zhike-content-output`（叙事声音规范、对客铁律、冷启动脚本铁律）
> 本技能专注视频号平台差异化规则，不重复通用的对客写作标准。

## 一、平台核心差异

视频号以**社交推荐**为核心（好友点赞→好友的好友看见），辅以算法推荐、兴趣推荐、位置推荐。与抖音纯算法推荐完全不同。

| 维度 | 抖音 | 视频号 |
|------|------|--------|
| 推荐核心 | 算法推荐（完播率、互动率） | **社交推荐**（好友点赞→裂变） |
| 标签数量 | 8个 | **3个**（太多被判为话题不准确） |
| 标签策略 | 三层结构全覆盖 | 精准3个 + **位置定位必加** |
| 封面 | 10-15字叠字必需 | 可选，≤8字；朋友圈分享卡裁成1:1 |
| 评论基调 | 反问快节奏 | **偏正式，完整句，可转发** |
| 冷启动 | DOU+投流 | **朋友圈+微信群转发** |
| 发布时间 | 晚20-22点 | 午11:30-13:00 或 晚22-23:00 |
| 第一条扶持 | 初始流量池200-500 | 第一条流量扶持较大 |

## 二、封面规则

- 发布前**单独设置**封面（从视频截帧或上传自定义图），不是编辑器中叠字
- 展示场景：个人主页大图 + 朋友圈分享封面卡
- 分享到朋友圈时卡片裁成 **1:1**，文字放中间偏下安全区
- **推荐：不叠字**，直接用画面最有张力的一帧
- 若叠字：≤8字，白字+细描边，居中下方1/4处
- 封面字不要写抖音那种悬念句——视频号不靠封面文字做划走判断

## 三、标签规则

- 控制在 **3个左右**，太多会被判定为话题不准确，降低推荐权重
- 选标签前**先在视频号内搜索**，选播放量最高的版本
- **必须加位置定位**（如"安龙县·德卧镇"），触发同城推荐
- 标签影响搜索推荐（微信搜一搜）和个性化推荐
- 推荐组合：`#贵州之客` + `#桨板` + `#贵州旅游` + 位置`安龙县·德卧镇`

## 四、评论策略

视频号的评论是**社交裂变引擎**：好友评论后，好友的好友在信息流看到"xxx评论过"。

### 评论引导（发完立刻自己写）
- 方向：拉本地好友的社交链
- 示例：`白水河拐过马鞭田这一段，从穿越机里看是一条绿色的带子。站在板上看是另一种颜色。你上次来马鞭田是什么时候？`
- 不用抖音的反问快节奏，用完整句子

### 回复规则
- 偏正式、可转发——用户可能截图分享评论
- 必须有称呼，尽量问句结尾
- 不用客服腔（禁"亲""宝""欢迎光临"）
- 不报价
- 评论字数8字以上权重更高

### 冷启动分发操作
1. 分享到**朋友圈**（配转发文案，不纯广告）
2. 转发到**所有相关微信群**（本地群/户外群/旅游群）
3. 让**团队所有人用个人号点赞+转发到朋友圈**——触发社交裂变
4. 有公众号的场合，在文章里嵌入视频号视频

## 五、回复话术库

| 场景 | 回复 |
|------|------|
| 问"这是哪里" | 黔西南安龙县德卧镇马鞭田村，白水河。从兴义开车不到一小时。你是本地还是计划来贵州旅行？ |
| 夸"拍得真好" | 谢谢，穿越机拍的，贴水面那段普通无人机飞不了这么低。你也在玩航拍吗？ |
| 问"能玩什么" | 桨板。码头就在视频里那个弯道旁边。我们有自己的基地，装备和教练都在现场。你之前划过桨板吗？ |
| 本地人留言 | 老乡。夏天的白水河比视频里更好看，最近水大。有空过来看看。 |
| 说"想去" | 周末早上出发，十点就在水上了。主页有更多信息。你想一个人来还是带朋友？ |
