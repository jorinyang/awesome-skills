# 黔西南旅游路线设计方法论

## 设计原则

1. **自有基地是核心锚点**：路线必须包含贵州之客至少一个自有基地（马鞭田桨板/犀牛洞探洞/笃山天坑速降），以此为锚点向外延伸
2. **官方资源做配角**：官方画册中的万峰林、马岭河等AAAA/AAAAA景区作为"建立认知"的背景，不是核心体验
3. **情绪弧线设计**：从"看风景"过渡到"走进风景"，最后用安静的场景收束
4. **地理半径优先**：一日游全程在一个县境内；两日游可跨兴义-安龙

## 路线模板

### 一日精品游模板
```
上午：贵州之客基地A（桨板，2.5h）
中午：本地午餐
下午：贵州之客基地B（探洞或速降，2.5h）
傍晚：免费景点收束（招堤/纳灰村等）
```
核心约束：不跨区域奔波，两场体验之间节奏舒适，结尾给安静的句号。

### 两日深度游模板
```
Day 1：官方景点（万峰林/马岭河等，轻松赏景）
Day 2：自有基地（桨板+探洞，深度体验）
```
设计逻辑：Day 1建立"黔西南认知"→Day 2打破认知——不是看风景，是走进风景里面。

## 已产出路线

### 路线一：「水面到地心」安龙极限一日精品游
- 08:30 兴义出发 → 09:30-12:00 马鞭田桨板 → 12:00 午餐 → 13:30-16:00 犀牛洞探洞 → 16:30 招堤 → 17:30 返回

### 路线二：「喀斯特的两张脸」黔西南深度两日游
- Day 1：万峰林 → 蛋炒饭 → 马岭河峡谷 → 峰林布依夜景 → 住宿
- Day 2：马鞭田桨板 → 安龙午餐 → 犀牛洞探洞 → 返回
