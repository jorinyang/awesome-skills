# 拆书

输入一本书，输出它在认知史里挪动的那一步。

## 拆书是什么

不是读后感，不是章节摘要，不是夸——是把作者的骨架抽出来摆桌上看。

一本书不是孤立物。每本认真写的书都是对一个问题的一次回答——这个问题之前有人答过，有共识压着，作者不满意，才动笔。所以一本书的价值不在它说了什么，在它挪动了什么：之前大家以为 X，作者说不对、是 Y。这个 X 到 Y 的差量（delta）才是书的贡献，其余是布景。

拆书顺着这场挪动走一条线。五件事，冷，抽骨架。最后一张认知地图——把这场挪动画成可视化的参考系图，再走两步做预测。

## 五件事

每一件单独问一遍。问完串起来——五件事是一条线，不是五个抽屉。

### 1. 核心问题

作者真正在答什么？

题目是 topic，问题是 question。topic 是"科技与未来"，question 是"科技演化有没有自己的方向"。拆书先把 question 从 topic 里剥出来——问题找错，后面全错。

问题不会凭空活着。一个问题还值得写一本书，是因为它的默认答案撑不住了。所以找问题时连着问一句：**作者冲哪个默认答案来的？**

怎么写：读导言/前言，找"我写这本书是为了……"那一句。读不到，看作者反复回到的那一处。

写完测试：这段拿去描述同领域另一本书，还成立吗？成立 → 太抽象，重写到具体。

### 2. 共识基线

这本书动笔之前，这个问题上大家站在哪？

价值是差量，量差量先得有零点。列 2-4 个主要立场——谁（流派/人物）+ 他们对这个问题的回答（一句话）。其中标明哪一个是共识。

基线要正对作者的不满。第 1 件事记下的那句——作者冲哪个默认答案来的——在这里兑现。

### 3. 独特洞见 + delta

作者带来了什么新东西？相对基线挪动了什么？

洞见形态四选一：
- **一个公式**——如 Shannon 的 H = -Σp log p
- **一个理论框架**——如 Darwin 的"变异 + 选择 + 时间"
- **一个模型**——如 Kahneman 的 System 1 / System 2
- **一个概念**——如 Taleb 的"反脆弱"

然后量 delta，一句话：**「之前大家以为 X，作者说：不对，是 Y。」** X 来自基线，Y 是作者的洞见。

delta 分三档：
- **修正**——共识大体对，作者补了一块
- **倒转**——共识答反了，作者翻过来
- **换轴**——共识问的维度就不对，作者换了参考系（最大）

**强制：必须列出作者独占的术语/列表/区分。** 每本好书都有作者独占的标签。KK《必然》必须有 12 动词列表，Marx 必须有生产关系/剩余价值，Kahneman 必须有 System 1/2。拆完看一眼：作者独占的标签出现了几个？0 个 → 你拆的不是这本书，是这本书所属的领域。

### 4. 核心观点 / 结论

合上书，作者要你带走的那个东西。往往就一两句话。

不能软。"作者认为人性是复杂的"是软话——什么不是复杂的？

另问一遍：**作者最想让读者带走的那一句话是什么？** 能 quote 最好，quote 不到用最贴近的复述。这一句要锋利到——读者合上书 10 年后还能想起来。

### 5. 精神内核 — 带走一件

合上书 10 年后只能记一件事——是哪一件？

形态五选一：
- **一个取景框**——一种看世界的方式（如 Darwin：变异+选择+时间）
- **一个模型**——一个结构性认知工具（如 Kahneman：System 1/2）
- **一个洞见**——一句被作者撬开的真相
- **一个概念**——作者铸的新词（如 Taleb：反脆弱）
- **一个金句**——作者亲笔写出、可直接 quote

三行内交付。形态标签 + 内容本体 + 一句话点为什么是这一件。

挑完三检：
- 合上书 10 年只能记一件事，就是这件吗？
- 这件事跟前 4 段重了吗？（重了=这是总结不是内核）
- 一个没读过的人，听了这一件，会不会想去翻原书？

## 第 6 段：认知地图——参考系图

前五段把骨架抽出来摆着。这一段把整个问题的认知格局画成一张图。

### 四步

1. **提炼轴**——各流派真正吵的是什么维度？那个维度就是轴。选轴本身就是立场：作者把哪个维度当作值得吵的，哪个问都不问。

2. **钉位置**——各流派 ●、作者 ★、旧共识文字标明，一个个钉上去。每个点说得出几何理由——谁离谁近（答案相似）、谁在谁的对角（针锋相对）。

3. **标 delta**——旧共识到作者 ★ 的距离：方向是什么，多远（修正/倒转/换轴）。

4. **走两步做预测**——在图上挪到一个作者没去过的位置，用作者的框预测：他站这个新位置会说什么？预测完回头对账。掌握不掌握就看这步。

### 图的规矩
- SVG 架构图：白底黑字 + 蓝 #3B5BDB 标注 + 红 #DC2626 强调，16:9，1920×1080，PingFang SC
- 流派 ●、作者 ★、旧共识文字标明
- 图下面给图注：每个点凭什么在那个位置，delta（含档位），作者轴外之物

## 灵魂三问 + 三道测试

**灵魂三问**（任何一个答不出→回头补）：
1. 零点问：这个问题之前的默认答案是什么？
2. 位移问：作者最独占的 move 是什么？能说出一句"之前大家以为 X，作者说 Y"？
3. 落点问：作者想让读者带走的那一句话是什么？

**三道测试**（每段写完都过）：
1. **替换测试**：这段拿去描述同领域另一本书还成立吗？能套 → 太抽象，重写
2. **指纹测试**：这段里有几个只有这本书才有的术语/概念/列表？0 个 → 拆的是领域
3. **delta 测试**：读完能一句话说出"之前大家以为 X，作者说 Y"吗？

## 怎么写

冷静、简洁、犀利、直白。不夸作者，不贬作者，不替作者辩护。

五段 + 认知地图。段内一气呵成，不绕弯。

**反翻译腔自查**：
- "进行讨论" → "聊"
- "通过 X 实现 Y" → "X 实现 Y"
- "这意味着..." → "也就是说..."
- 写完默念一遍，卡的地方整句重写

**禁切痕风**：别用"这一刀""锋利""钉死""砸实"这类自我修辞。内容够不够力，读者自己看得出。

## 怎么找材料

- 如果用户只给书名 → 先 web_search 找作者、导言、目录、核心论点的二手解读。再查这个问题的认知史

- 如果是经典书 → 可以靠 LLM 内部知识，但要默问自己：这条是书里实际有的，还是我编的？
