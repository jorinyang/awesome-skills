# 批量化适配规则表（通用版）

> 源自千问办公 AI 大赛内训《02-批量化适配规则》的通用化提炼。数字阈值是实战起点，按项目校准；结构比数字更重要。

## 1. 采集表字段（最少集）

客户/日期/对接人 | 行业 | 参训部门职能构成（带占比） | 参训人员构成（高管/中层/骨干/技术占比 + KP 是否到场） | 人数 | 目标工具熟练度 | 培训侧重排序 | 特殊要求（逐条） | 交付目标（购买/参赛/深度服务+优先级） | 资源状态（账号/额度） | 讲师助教

补充动作：拿到客户名称先查工商信息（成立时间/注册资本/参保人数/经营范围）——行业归类校验 + 规模判断。

## 2. 受众 → 表达版本

| 条件 | 版本 | 调整 |
|---|---|---|
| 高管 ≥30% 或 KP 在场 | 高管版 | 认知模块全量；实操改"看演示+提问"；转化模块加重 |
| 业务骨干 ≥50% | 业务版 | 认知精简 30–40%，省出时间给跟练；案例加重 |
| 技术 ≥30% | 技术版 | 方法论展开；技术模块加重 |
| 混合无主导 | 标准版 | 不调整 |
| 两极混合 | 分段版 | 上午高管版 / 下午业务版 |

## 3. 双轴案例选择

- **行业轴** → 认知/理念案例（讲行业故事）
- **职能轴** → 实操/演示案例（讲岗位场景）
- 优先级：自有已验证 > 官方/通用库 > 保底场景；不命中 → 邻近行业/职能 → 通用保底组合

## 4. 人数 → 组织形式

| 人数 | 组织 | 物料/人力 |
|---|---|---|
| ≤30 | 4–6 人小组制，逐组核对 | 物料人手一份 |
| 30–70 | 同桌两人制，互查+抽检 | 助教 1/25 人 |
| >70 | 全班互动，跟练保底档为主 | 助教团 |
| 极端（过多/过少） | 触发上报，不现场接话 | — |

## 5. 模块开关与时长守恒

每个开关写三样：**默认态 / 触发条件 / 借还时长明细**。生成配置后按时段（上午/下午）分别验算闭合。

## 6. 特殊要求三分流

| 类型 | 处理 |
|---|---|
| 标版内微调（换案例/调侧重） | 免费，直接写入配置单 |
| 超标准化边界（加课/深度辅导/定制开发） | 收费口径回应，线索转 BD |
| 不合理（压缩时长/超额人数/讲竞品） | 上报协调；不主动缩减；按红线拒绝 |

## 7. 四件套派生门禁

| 交付物 | 派生规则 | 校验门禁 |
|---|---|---|
| PPT | 模块页数配额；案例槽替换；受众版定表达角度；提纲式 | 页数核对；讲师元信息关键词 grep=0；案例名与配置单一致 |
| 学员自学书 | 固定章节结构；行业章替换；定位"课上一练、案头一月" | 章节齐全；数字口径与 PPT 一致 |
| 题库 | 题型×模块配额矩阵；**只考开考前已讲授内容**；三格式（系统 JSON/学员 MD/答案 MD） | json 校验；配额核对；标签齐全 |
| 工具包 | 单件四要素：用途+何时用+空白模板+要点 3–5 条；按开关增减 | 件数与开关一致；与课程内容逐字一致 |

**交叉一致性**：四件的模块名/数字口径/案例名必须一致；改动任一须同步其余三件。版本号 = 标版版本 + 场次序号。
