# 客户信息采集表 + 场次配置单（空白模板）

> **用法**：把与客户对齐的会议纪要+转写交给 AI，AI 按本模板填充输出本场专用配置单。
> **配套**：适配规则书（推导规则编号来源）、课程框架（红线与模块定义）。

## 填写纪律（AI 填写时遵守）

1. 只填纪要/转写中实际出现的信息；未出现标【未提及】，禁止编造、禁止用默认值冒充客户信息
2. 推导区每条结论注明依据：采集表字段编号 + 规则书规则编号
3. 标【未提及】且影响推导的字段，自动汇入文末《待客户确认清单》
4. 客户要求与课程红线冲突时，按红线处理并在"特殊要求分流"中注明
5. 推导可修正：改推导区并留修改记录，不直接改配置单结果
6. 客户名称确定后先查工商信息（成立/注册资本/参保人数/经营范围），填入 A+ 区；查询失败标记后继续，不阻塞

## A · 客户信息采集表

| # | 字段 | 内容 | 提取线索（在纪要/转写中找什么） |
|---|------|------|------------------------------|
| A1 | 客户名称 / 行业 | | 公司名、所属行业；归入项目行业清单 |
| A2 | 参训部门职能 | | 参训部门及占比（如"主要是销售和运营"） |
| A3 | 参训人员构成 | | 高管/中层/骨干/技术占比；KP 是否到场、是谁 |
| A4 | 参训人数 | | 具体数字或区间（"三十来人"记为约 30） |
| A5 | 目标工具熟练度 | | 对相关平台/工具的使用程度（熟练/用过/没用过） |
| A6 | 培训侧重方向 | | 客户明确表达的期望排序 |
| A7 | 特殊内容要求 | | 客户点名的内容，逐条记录 |
| A8 | 交付目标 | | 购买/报名/深度服务的信号与优先级；预算、决策链 |
| A9 | 日期 / 地点 / 形式 | | 时间、地点、线上或线下、时长要求 |
| A10 | 资源状态 | | 账号开通、额度/积分是否充足 |
| A11 | 讲师 / 助教 | | 我方主讲与助教安排 |
| A12 | 对接人 | | 客户侧与我方对接人 |
| A13 | 其他关键信号 | | 客户原话中的诉求、顾虑、痛点（保留原话，标注角色） |

### A+ · 工商信息补充（自动查询）

| 字段 | 内容 | 用途 |
|------|------|------|
| 查询状态 | | 成功 / 失败 / 未提供客户名称 |
| 成立时间 / 注册资本 / 经营状态 | | 企业基本盘 |
| 人员规模（参保人数） | | 规模判断——影响组织形式与案例口径 |
| 经营范围摘要 | | 行业归类校验 |
| 行业校验结论 | | 与客户自述行业是否一致；不一致以工商为准并在推导区注明 |
