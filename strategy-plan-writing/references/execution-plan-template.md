# Per-Platform Execution Plan Template

Use this structure when writing the execution-tier (v2) document for any multi-platform cold-start launch. Adapted from the 晏家湾星途营地 execution plan session.

---

## Per-Platform Section Template

Each platform gets a section with these subsections:

### X.1 Account Setup

Table with: account name, ID, avatar, bio, background image, menu structure (for 公众号), POI (for 抖音), linked accounts.

### X.2 Content Types & Script Templates

For each content type:
- Type name
- Duration (video) or format (text/image)
- Percentage allocation in content mix
- Script/scaffold template
- 3-5 example scripts

### X.3 Publishing Cadence

Weekday-by-weekday schedule showing which content type goes live when. Include best-practice publish times for the platform.

### X.4 Initial Editorial Calendar

For cold-start: a 30-day day-by-day calendar with specific titles/topics for each post. This is critical — a vague "post 3x/week" plan is useless to a team starting from zero.

### X.5 Paid Promotion Strategy (if applicable)

Phased approach (test → optimize → sustain) with specific budget numbers and targeting parameters per phase.

### X.6 Interaction/Conversion SOP

Comment reply templates, DM conversion scripts, community management guidelines specific to the platform.

### X.7 KPIs

Month 1 / Month 3 / Month 6 targets for: followers, average views, engagement rates, conversion numbers.

## Cross-Platform Section

### Content Synergy ("一鱼多吃")

Matrix table mapping which raw content asset feeds which platform output.

| Raw Asset | Platform A | Platform B | Platform C |
|-----------|-----------|-----------|-----------|
| Aerial footage | Hero image | 15s clip | Cover image |

### Weekly Production Rhythm

Day-by-day workflow:
- Monday: editorial meeting
- Tuesday: shoot day
- Wed-Thu: production days
- Friday: review
- Saturday: publish + live
- Sunday: data review

### Asset Management Structure

Recommended folder hierarchy:
```
素材库/
├── YYYY-MM-W1/
│   ├── 航拍/
│   ├── 活动/
│   ├── 人物/
│   ├── 环境/
│   └── 已发布/
```
