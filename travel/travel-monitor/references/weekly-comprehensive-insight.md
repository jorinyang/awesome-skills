# 周度综合洞察分析 — Cron Prompt 模板

> 与 `travel-monitor` 周度分析工作流（聚焦竞品动态）不同，综合洞察分析**横跨行业资讯 + 竞品动态两个知识库节点**，执行 6 维度 LLM 交叉分析，产出面向管理层的战略洞察报告。

## 适用场景

- Cron 每周四/五执行（或与周报同日但错开时段）
- 手动触发：策略会议前需要全面行业+竞品交叉分析

## Step 1: 列出本周文档

用 lark-cli 列出两个节点的文档：
```
lark-cli wiki '+node-list' --parent-node-token <TOKEN> --space-id 7643710721485753535 --as bot 2>&1 | tail -n +2
```

筛选标题含最近7天日期（格式 YYYY-MM-DD_xxx）的文档，排除含"测试"的。

## Step 2: 读取文档内容

对每个本周文档，通过飞书 Open API 读取 raw_content：
- 用 FEISHU_APP_ID=cli_aa9ead14c2641cc3 和 FEISHU_APP_SECRET 环境变量获取 tenant_access_token
- GET /open-apis/docx/v1/documents/{obj_token}/raw_content
- 只读最近7天内的文档

## Step 3: 多维洞察分析

基于所有文档内容，按6个维度分析：

**维度1 — 行业趋势信号**：识别3-5个值得关注的趋势，每个含：趋势描述、证据来源（引用文档标题）、对贵州之客的影响评估

**维度2 — 竞品态势图谱**：四个方向（探洞/天坑/桨板/坝盘）各自活跃度、竞品新动作（新产品/价格变动/营销创新）、威胁等级标注（🔴高 🟡中 🟢低）

**维度3 — 政策与合规窗口**：本周政策变化、红利窗口期、合规风险

**维度4 — 供需缺口与机会**：基于数据找出供需缺口，给出2-3个可操作的产品/运营建议

**维度5 — 风险与预警**：负面信号按紧急度排序（本周关注/本月关注/趋势性）

**维度6 — 下周采集建议**：基于本周发现，建议下周重点采集的方向和关键词

## Step 4: 创建洞察报告文档

## 关键差异：综合洞察 vs 竞品周报

| 维度 | 综合洞察分析 | 竞品周度分析 |
|------|------------|------------|
| 数据源 | 行业资讯 + 竞品动态 两个节点 | 仅竞品动态节点 |
| 分析维度 | 6维（趋势/竞品/政策/机会/风险/采集） | 4维（统计/重点/对比/关键词） |
| 面向对象 | 管理层战略决策 | 运营团队竞品跟踪 |
| 输出文档 | 存于行业资讯节点 | 存于竞品动态节点 |
| 关键动作 | 产品/品牌建议 + 风险预警 | 竞品对标 + 关键词审计 |

## 已验证效果

2026年第22周执行：从13份文档（12行业+1竞品）中识别出马蜂窝安顺三洞项目的直接竞争威胁、自动采集管道大面积失效的数据质量问题、以及票根经济+国家步道等政策利好。报告+摘要成功推送至贵州之客群。
