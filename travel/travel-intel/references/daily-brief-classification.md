# 每日简报分类实践指南

> 基于 2026-06-04 每日简报生成实战总结。

## 分类流程

```
全部当日文档 (wiki +node-list → 筛选 YYYY-MM-DD_ 前缀)
    ↓
一级分类：关键词匹配
    ├─ 贵州直接关键词 (贵阳/贵州/旅发/黔/兴义/万峰林…) → 高优 🔴
    ├─ 户外/竞品关键词 (探洞/天坑/桨板/SUP/漂流/溯溪) → 高优 🔴
    ├─ 政策关键词 (办法/规划/通知/统计公报/印发/十五五) → 政策 🏛️
    ├─ 噪音模式 (迈点空间/迈点今日头条/酒店采购需求/供应链产品/酒店项目信息/内容开放平台) → 丢弃
    └─ 其余 → 常规 🟡
    ↓
二级过滤（高优内部）：区分「贵州本地」vs「户外/竞品」
    ├─ 含贵阳/贵州/旅发/黔 → 贵州本地 📍（callout 红色高亮）
    └─ 仅含漂流/避暑/徒步 → 户外/竞品 🏕️（普通列表）
```

**"黔" 字天坑 (2026-06-05)**：`黔` 在 HIGH_PRIO_GUIZHOU 关键词列表中，会命中「黔江区」（重庆区县，非贵州）、「黔东南」「黔西南」「黔南」才是贵州。分类脚本需加例外：匹配到 `黔江` 时不触发贵州高优。

### 闻旅非旅游内容噪音 (2026-06-21 补充) ★

闻旅 L2 产出中包含部分完全无关的非旅游内容，标题无任何旅游关键词，应直接丢弃：

| 模式 | 示例 | 说明 |
|------|------|------|
| 工会节日活动 | `送粽子 讲安全 做香囊，红河州工会这样陪职工过端午` | 工会福利报道，非旅游 |
| 文艺比赛 | `第十六届云南省青年演员比赛丽江市初评圆满落幕` | 演员/文艺比赛，非旅游 |
| 过时疫情内容 | `德尔塔病毒会是压倒旅行社的最后一根稻草么？` | 2021年疫情旧文，已无时效性 |

**匹配逻辑**：
```python
# 2026-06-21 补充：闻旅及其他源的非旅游噪音
NON_TOURISM_PATTERNS = [
    r'工会.*(过|节日|端午|中秋|春节)',  # 工会活动
    r'.*(青年演员|歌手|舞蹈|戏曲).*比赛',  # 文艺比赛
    r'德尔塔病毒|新冠病毒.*变异',  # 过时疫情内容
]
```

> ⚠️ 这些模式应在「旅行相关性过滤」（阶段2）之后检查，因为部分条目可能因含"旅游"弱相关词通过旅行过滤，但实质为工会/文艺活动报道。

### 闻旅部门导航链接 (2026-06-19 补充) ★
- 省份/直辖市全称 + 旅游/文化 + 厅/局/委员会（如"海南省旅游和文化广电体育厅"、"重庆市文化和旅游发展委员会"）
- 部分含活动动词但主体为部门工作动态（如"红河州文化和旅游局举行...党组织轮值活动"）

这些条目对贵州之客无业务参考价值。分类脚本应增加部门导航过滤：

```python
# 2026-06-19 补充：闻旅部门导航链接
DEPT_NAV_PATTERNS = [
    r'^[京津沪渝冀晋辽吉黑苏浙皖闽赣鲁豫鄂湘粤桂琼川黔滇藏陕甘青宁新]{2,6}(省|市|自治区).*(旅游|文化).*(厅|局|委员会)$',
    r'.*(文化和|旅游和).*(体育厅|广电|发展委员会)$',
]

def is_dept_nav(title):
    """纯部门名称，非实质旅游内容"""
    for pat in DEPT_NAV_PATTERNS:
        if re.match(pat, title.strip()):
            return True
    return False
```

> ⚠️ 注意区分：含实际景点/产品/数据关键词的文旅厅通知不应被过滤（如"贵州省文旅厅发布2026暑期旅游数据"含"数据"应为政策类）。仅纯部门名称/部门活动报道应丢弃。

## 高优文档信息提取回退

L2 ingestor 创建的文档为骨架格式（无正文、无 bookmark URL），无法 curl 原文提取摘要：

1. 有 callout → 提取 callout 中的标题文本
2. 无 callout → 从文档标题（去掉日期_来源_ 前缀）生成 50-80 字概要
3. 概要写法：`来源 + 影响评估一句话`，不做虚构性内容补充

## 分类脚本幻匹配陷阱 (2026-06-06)

分类脚本可能将不含任何贵州关键词的文档错误标记为「贵州高优」。实例如"引客入滇见实效 数字赋能文旅发展 ——百城万人游红河"（云南红河，非贵州）被标记为高优——原因可能是 JSON 输出中标题含控制字符导致正则匹配行为异常，或 OTHER 分类逻辑中某个分支误判。

**强制验证步骤**：分类完成后，必须逐条人工复查所有「贵州高优 🔴」分类结果，确认标题确实包含贵州地名关键词（贵州/贵阳/黔西南/兴义/万峰林等），而非他省内容。此项验证不可省略。

## 简称交叉污染（补充 2026-06-06）

省际简称相似可能导致误判：「滇」（云南）≠「黔」（贵州），但分类脚本对含简称的标题可能产生边界行为。规则补丁：`HIGH_PRIO_GUIZHOU` 匹配后，增加否定列表检查——若标题含「滇」「川」「渝」「桂」等其他西南省份简称但无贵州地名，不应标记为贵州高优。

## `_other_` 源标签异常 (2026-06-06)

当日全部 88 条文档以 `2026-06-06_other_` 前缀入库，而非正确的 `pinchain_` / `meadin_wl_` / `meadin_jq_` 源标签。这意味着 l2_ingestor.py 的 source 提取逻辑可能在特定输入格式下回退到 `other` 兜底值。此异常不影响简报分类（因分类仅依赖标题关键词），但影响来源追溯和审计。待排查 ingestor 的 source 字段解析路径。

## 解析陷阱：内嵌引号导致正则漏检（2026-06-09）

`wiki +node-list` JSON 中标题可能含 ASCII 双引号（如 `马蜂窝联合安顺市文体广电旅游局发布"山地新玩法宝典"`），JSON 中正确转义为 `\"`。用正则 `"title":\s*"([^"]*)"` 提取时会提前截断到内嵌引号前，导致该文档被漏检。

**实例**：2026-06-09 分类脚本用正则提取，遗漏「马蜂窝联合安顺市文体广电旅游局发布"山地新玩法宝典"」——该文档含「安顺」（贵州）+「马蜂窝」（竞品），应为🔴高优。

**对策**：优先用 `json.loads()` 解析（JSON 已正确处理内嵌引号转义），仅当控制字符导致 `JSONDecodeError` 时才回退清洗或正则。详见 `references/briefing-execution-notes.md` 解析陷阱章节。

## 简报核心洞察生成

从当日全量文档中提炼 3-4 条跨分类洞察，而非逐条罗列：

- 找跨文档的主题共性（如"入境游"在多篇中出现 → 行业趋势）
- 找与贵州之客业务的交集（如贵阳中旅韩国团 → 贵阳入境游机会）
- 找政策信号（如多地免票 → 暑期竞争格局）
