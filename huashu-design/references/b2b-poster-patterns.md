# B2B 推介海报设计模式

> 面向旅行社、研学机构等合作单位的单页推介材料。与对客海报不同：信息密度更高、视觉更克制、功能性优先。

## 核心原则

1. **信息层级 > 视觉冲击** — B2B 受众3秒内抓取核心数据（接待量/价格/区位），不是被情绪打动
2. **上下分区优先** — 上部展示氛围（照片或设计背景），下部承载全部信息。不要在照片上大面积叠文字
3. **照片退路** — 当没有高质量实拍照片时，直接使用纯设计背景（山形剪影/水面波纹/抽象地理元素），不要硬用低质量照片
4. **数据要跳出** — 核心数字（价格/容量/配比）用高对比色或独立统计栏呈现，不要埋在段落里

## 布局模式

### 模式 A：实拍照片 + 上下分区（有高质量照片时）

```
┌─────────────────────┐
│                     │
│   实拍照片（全宽）    │  上部：照片，顶部渐变遮罩叠标题
│   标题 + 地点叠在    │  人物/产品主体不能被任何 element 遮挡
│   顶部渐变遮罩上     │
│                     │
├─────────────────────┤
│  1,000人/日 │ 1:6  │  统计栏（可微微上移制造衔接感，但不能压到照片主体）
├─────────────────────┤
│  场地设施  │ 活动概况│
│  交通到达  │ 合作模式│  四卡信息网格
├─────────────────────┤
│  品牌落款 + 联系方式  │
└─────────────────────┘
```

**坑**：统计栏用负 `top` 边距上移时，必须确认不遮挡照片核心主体（人物/产品）。如果冲突，放弃上移，让统计栏完全在纯色区内。

### 模式 B：纯设计背景（无照片或照片质量不够时）

```
┌─────────────────────┐
│       微光晕         │
│   层叠山脉剪影（2层） │  上部：抽象山水背景
│   水面波纹（多层）    │  可选：极简桨板人剪影作为视觉锚点
│   桨板人剪影 + 光晕  │  标题叠在顶部
│   标题 + 地点        │
├─────────────────────┤
│  统计栏（绿色高亮数字）│
├─────────────────────┤
│  四卡信息网格        │
├─────────────────────┤
│  品牌落款 + 联系方式  │
└─────────────────────┘
```

**设计元素建议**：
- 山脉：2层 `clip-path` 多边形剪影，深绿→墨绿色阶
- 水面：`clip-path` 波纹 + 多层 `border-radius: 50%` 的水平线模拟涟漪
- 视觉锚点：极简人物+桨板剪影，加 `radial-gradient` 光晕提亮
- 色系：深蓝底 (#0b1018) → 墨绿山脉 (#153a3c / #1a4a4f) → 荧光绿点缀 (#5CE68C)

## 内容结构（B2B 单页四要素）

| 区块 | 内容 | 形式 |
|------|------|------|
| 标题区 | 基地名称 + 英文小标签 + 位置 | 大字，英文标签增加国际感 |
| 统计栏 | 接待量 / 教练配比 / 保额 / 价格 | 四等分横条，核心数字高亮色 |
| 详情卡 | 设施 / 活动 / 交通 / 合作 | 2×2 网格，每卡 2-3 句 |
| 落款 | 品牌名 + slogan + 联系方式 | 左右分布 |

## 与对客海报的区别

| 维度 | B2B 推介海报 | 对客海报 |
|------|:--:|:--:|
| 目标 | 合作决策 | 种草/转化 |
| 情感温度 | 专业、可靠 | 向往、兴奋 |
| 信息密度 | 高（四组数据+四卡） | 低（1-2个核心卖点） |
| 照片依赖 | 可选（纯设计可替代） | 强烈依赖（真实感=信任） |
| CTA | "合作联系" | "主页可约/私信" |
