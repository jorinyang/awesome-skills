# 活动物料设计模式 · Event Materials Design Patterns

## 适用场景

为贵州之客（及类似户外/旅游品牌）生成活动宣传海报、签到背景板、分区物料效果图、氛围装饰设计。与 B2B 推介海报（`b2b-poster-patterns.md`）不同，活动类设计面向 C 端，需要节日氛围 + 可落地制作信息。

---

## 一、海报设计（活动宣传用）

### 参考风格：马鞭田桨板基地海报

**核心要素**：
- 深绿→青绿→墨绿渐变背景，模拟水域/户外感
- 动态波浪层（CSS animation `drift` + SVG wave patterns）
- 太阳光晕（radial gradient 右上角）
- 白色闪烁粒子（sparkle animation）
- 标题用金色渐变文字（`-webkit-background-clip: text`），字重 900
- 半透明毛玻璃卡片承载内容
- 底部署名区深色半透明渐变条

**色彩规范**：
```
主背景: linear-gradient(170deg, #0a3d2e → #155e3a → #1a7a45 → #0d8c50 → #00a35c → #00b870 → #00cc80 → #00855a → #006b42 → #004d2e)
标题渐变: linear-gradient(180deg, #ffffff → #ffeb99 → #ffd166)
日期徽章: #ff6b35（撞色橙）
半透明卡片: rgba(255,255,255,0.12) + backdrop-filter: blur(8px)
```

**海报禁止出现的内容（用户明确要求）**：
- ❌ 套餐价格
- ❌ 人次/人数统计
- ❌ 应急预案
- ❌ 人员配置
- ❌ 长篇文字说明

**海报必须包含的内容**：
- ✅ 活动主题（大字标题）
- ✅ 日期
- ✅ 地点
- ✅ 活动区域/玩法概述（4-5张卡片，每张一行简述）
- ✅ 时段信息
- ✅ 落款（基地名/品牌名）

**渲染方式**：HTML → Playwright 全页截图 PNG。不要用 SVG→cairosvg 做海报（颜色渐变和动效出不来）。

### 尺寸
- 竖版海报（朋友圈/小红书）：800×1200 或 1080×1920

## 二、活动区域道具/背板设计（落地制作用）

### 参考风格：国潮绿调KT板

**核心要素**：
- 主色调：绿（`#2D8B4E` / `#1A6B3A` / `#F0F8F0`）
- 辅助色：金色描边（`#C8960C` / `#F5D06B`）
- 强调色：红色仅用作小面积点缀（龙舟、标语），不做主色调
- 材质：10mm KT泡沫板 + 异形切割 + UV喷绘
- 风格：现代国潮插画（Guochao），扁平矢量风
- 角色：可爱的粽子精灵、鸡蛋精灵等萌系拟人角色
- 布局：多层拼接结构，中间主背板 + 左右立牌/展板
- 背景：纯白产品稿，无户外场景、无天空草地树木

**禁止的设计错误（用户已纠正多次）**：
- ❌ 木头材质（"木头太丑了"）→ 必须是KT泡沫板喷绘
- ❌ 红色主色调 → 端午≠纯红，绿调才贴合粽叶/自然/水域
- ❌ 风景场景图（蓝天草地远山）→ 用户要的是产品效果图，不是风景画
- ❌ 蓝图画板风格 → 用户要的是视觉成品，不是工程图
- ❌ 签到台嵌入图中 → 有时用户只要单独的背板效果图，不要台桌

**渲染方式**：SVG → cairosvg → PNG。适合平面矢量设计稿，字体用 `Noto Sans SC, SimHei`（cairosvg 不支持 PingFang SC）。

### 设计检查清单

交付前逐项自检：
- [ ] 主色调是绿色不是红色？
- [ ] 材质标注为KT泡沫板/PVC板，不是木头？
- [ ] 是产品白底稿，没有户外风景？
- [ ] 有可爱的拟人角色（粽子/鸡蛋/龙舟精灵）？
- [ ] 标注了材质、尺寸、数量？
- [ ] 中文清晰可读（cairosvg + Noto Sans SC 验证）？

## 三、设计迭代教训

### 教训1：不看参考就出手 = 必返工
用户发了4张参考图明确风格方向后，仍按自己理解的"端午=红色"出图，导致多次返工。
**规则**：用户提供参考图时，先用 vision_analyze 逐张分析，提取色调/材质/排版/元素风格，汇总确认后再动手设计。

### 教训2：材质不对 = 全盘否定
用户说"泡沫板喷绘"时，第一版用了木头材质，直接被否。KT板≠木板，国潮插画风≠写实木纹。
**规则**：听到材质关键词（KT板/泡沫板/亚克力/喷绘布）时，设计稿要如实呈现该材质的视觉特征。

### 教训3：产品稿≠场景图
用户要的是"效果图"——展示这块板子长什么样，不是这个板子放在哪里。
**规则**：默认纯白底产品mockup，用户明确要场景合成时再加环境。

### 教训4：多图嵌入的定位锚必须用文档正文文本
用图片caption文本做 `--selection-with-ellipsis` 的锚点会失败（因为caption文本不在文档body中）。必须用文档正文中存在的标题或段落文本。
