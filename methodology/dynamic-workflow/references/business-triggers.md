# 通用业务触发场景

基于用户历史对话模式和工作类型，定义 task-type 关键词无法覆盖的通用业务触发。**不绑定任何公司/品牌。**

---

## 通用业务触发矩阵

### U1: 数据采集与报告生成

| 触发场景 | 任务特征 | 推荐模式 |
|---------|---------|---------|
| 多源数据汇总 | 多个数据源并行采集 → 合并去重 | ② Fanout |
| 周期性报告（日报/周报/月报） | 多维度分类 + 分组汇总 | ② Fanout + ① Classify |
| 深度分析报告 | 跨维度 LLM 分析 + 趋势判断 | ② Fanout + ⑥ Loop（新发现 → 深挖） |
| 数据质量校验 | 规则扫描 → 过期/异常标记 | ② Fanout（批量并行扫描） |
| 关键词批次搜索 | N 个关键词 → 各自搜索 → 汇总 | ② Fanout |

### U2: 内容创作与多格式分发

| 触发场景 | 任务特征 | 推荐模式 |
|---------|---------|---------|
| 同一内容多版本产出 | 短/中/长版，或多渠道版 | ④ Gen-Filter（生成多版 → 按渠道 rubric 筛选） |
| 多格式内容套装 | 文案 + 视觉 + 页面 三件套 | ① Classify（按格式） + ② Fanout（并行产出） |
| 创意多方案 | 同一需求，多种风格/方向 | ④ Gen-Filter |
| 内容质量审查 | 发布前合规/准确/风格审查 | ③ Adversarial（创作者 ≠ 审查者） |
| 多渠道分发 | 同一内容推送多平台 | ② Fanout（各渠道独立推送） |

### U3: 工具/技能管理与编排

| 触发场景 | 任务特征 | 推荐模式 |
|---------|---------|---------|
| 批量配置更新 | 多个文件同时需要修改 | ② Fanout |
| 新工具创建 + 测试 + 文档 | 跨代码/测试/文档三领域 | ① Classify + ② Fanout |
| 跨工具冲突检测 | 检查触发词/依赖/路径冲突 | ③ Adversarial（独立验证冲突矩阵） |
| 批量迁移/归档 | 多个文件/配置操作 | ② Fanout |

### U4: API 批量操作

| 触发场景 | 任务特征 | 推荐模式 |
|---------|---------|---------|
| 批量数据移动/分拣 | 分类节点 → 多目标移动 | ② Fanout（注意限流） |
| 批量 CRUD | 多条记录创建/更新/删除 | ② Fanout |
| 多表/多源联查 | 跨数据源汇总查询 | ② Fanout + Synthesize |
| 定时批量任务 | 周期性触发的大量操作 | ② Fanout（BATCH 分批） |

### U5: 项目运营与决策

| 触发场景 | 任务特征 | 推荐模式 |
|---------|---------|---------|
| 竞品/市场深度分析 | 多维度对比 + 趋势判断 | ② Fanout + ⑥ Loop |
| 多线产品规划 | 产品 + 定价 + 营销 并行 | ① Classify + ② Fanout |
| 异常事件/客诉处理 | 分类 → 根因 → 修复方案 | ① Classify + ⑥ Loop + ③ Adversarial |
| 跨团队协作任务 | 多负责人、多截止日期 | ① Classify + ② Fanout |
| 方案选型决策 | 多候选 + 多标准 | ④ Gen-Filter + ⑤ Tournament |

### U6: 工作流编排联动

| 触发场景 | 任务特征 | 推荐模式 |
|---------|---------|---------|
| 结构化规划 Phase 5 并行模块 | 拆解时遇到 3+ 并行子模块 | ② Fanout（自动调用快速版） |
| 多产出物交叉审核 | 多交付物同时需要审查 | ③ Adversarial（每个产出独立验证） |
| 任务模糊需要先澄清 | 输入过于模糊无法直接拆解 | 暂停，先 Clarify |
| 技术选型/架构决策 | 多方案需要系统化比较 | ④ + ⑤ |

## 触发规则

### 自动触发条件（不必等用户说"审计"）

1. **U1 报告类**：任务涉及 ≥ 2 个数据源且需要汇总
2. **U2 内容类**：同一产出需要 ≥ 2 个版本或格式
3. **U3 工具类**：涉及 ≥ 3 个文件/配置的批量修改
4. **U4 API 类**：涉及 ≥ 5 次同类型 API 调用（有批量优化空间）
5. **U5 决策类**：涉及 ≥ 3 个候选方案或评估维度
6. **U6 编排类**：结构性规划检测到 ≥ 3 个并行模块

### 触发优先级

```
1. U1-U6 业务触发（本文件）  ← 最高优先
2. T1-T7 任务类型（SKILL.md Layer 1）
3. D1-D8 维度计分上调（SKILL.md Layer 2）
```

交叉触发时，取覆盖范围最大（Agent 最多、模式最复杂）的组合。
