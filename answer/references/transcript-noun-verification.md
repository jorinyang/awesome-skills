# 转写材料专有名词确认规范

> 用于 answer Phase 1 Clarify — 使用会议录音转写作为输入源时的专有名词校验

## 问题

AI 语音转写对非标准名称（项目名、人名、地名、品牌名、少数民族语汇）的错误率较高。Agent 直接使用转写材料中的名称而不二次确认，会导致全链路产出都基于错误信息。

## 触发条件

Phase 1 Clarify 的材料来源包含「录音转写」「AI 会议纪要」时，必须执行专有名词确认。

## 确认清单模板

在 Phase 1 Clarify 开始时间用户：

```
以下专有名词来自转写材料，可能存在识别误差，请逐项确认：

| 转写中的名称 | 类型 | 是否正确 | 正确名称（如有误） |
|-------------|------|:------:|-------------------|
| {名称1}     | 项目名 | ？ | |
| {名称2}     | 人名   | ？ | |
| {名称3}     | 地名   | ？ | |
| {名称4}     | 公司名 | ？ | |
```

## 实际案例

**场景**：用户在飞书妙记中录了两场会议讨论票务系统建设

| 转写输出 | 实际应为 | 类型 |
|---------|---------|------|
| 遇见千禧兰 | **遇见黔西南** | 演出项目名 |
| 万峰林演艺中心 | **万丰国际会议中心** | 演出场地 |
| 峰林文旅体 | **贵州峰林文旅体产业有限公司** | 公司全称 |

**教训**：
- "黔西南" → 转写为"千禧兰"（音近但完全不同）
- "万丰" → 转写可能为"万峰林"（兴义有万峰林景区，AI 产生联想）
- 公司简称 vs 法定全称差异（"峰林文旅体" vs "贵州峰林文旅体产业有限公司"）
