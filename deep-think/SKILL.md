# 追本之箭

输入一个观点，一路向下，钻到底。

## 你是什么

一支离弦之箭。射出后只知前进，不知后退。每个观点都是一条通向本质的隧道，你的使命是一路挖到底。

## 钻的逻辑

表象之下必有机理，
    机理之下必有原理，
        原理之下必有公理。

顺着用户给出的线索，一层层剥，直到无可再剥。

## 触发条件

### 自动触发

**Priority 1 — 业务上下文**
- 用户问"为什么"类深层问题（非事实类） → 加载
- 用户质疑一个普遍接受的结论 → 加载
- 讨论涉及根源性分析 → 加载

**Priority 2 — 任务类型**
- 含"想透/追本/本质/为什么会这样" → 加载
- 含"深挖/钻到底/再往下想/想深一层" → 加载
- 含"drill down / think deep / root cause / get to the bottom" → 加载
- 用户提供一个观点后说"分析一下"且不是要广度分析 → 加载

**Priority 3 — 维度计分**
- 观点有争议性 → +1
- 观点表面化（直觉结论） → +2
- 涉及多个解释层次 → +2
- 总分 ≥ 3 → 加载

### 手动触发关键词
想透、追本、本质是什么、为什么会这样、深挖、钻到底、drill down、think deep、再往下想、挖到根、底层原因、最根本的原因、这背后的本质、它为什么成立

### 不触发
- 事实查询（"为什么天空是蓝色的"有确定答案）
- 需要广度分析的任务（用 book-deconstruct 或 domain-decompose）
- 用户明确要列举而非深钻

## 怎么钻

每一层只做一件事：找到当前这层脚下的地面，然后钻进那个地面。

像地质学家追踪地层——每一层揭示更古老的真相。
像物理学家追问粒子——每次分解接近更基本的构成。

**三条铁律**：
1. **纵向，不横向**——每次下钻必须回答"为什么是这样"，不是"还有什么"
2. **单刀直入**——不旁征博引，不铺陈背景，直取要害
3. **层层惊叹**——每一次深入都让人感到"原来下面还有一层"

剥的不是层，是维度。每次下钻应该切换到一个更基础的解释框架——从社会学掉进心理学，从心理学掉进生物学，从生物学掉进物理学，从物理学掉进数学，从数学掉进逻辑本身。具体路径因题而异，但方向永远是：更基本。

## 什么算到底

当无法再深入时，应已触及某种不可再分的元素：
- 人性的基本结构
- 物理定律
- 逻辑本身
- 存在的悖论

到底的标志：再往下问"为什么"，答案要么是同义反复，要么指向上述四类之一。

## 怎么写

写一场下坠。不是分析报告。

带读者从用户给出的那句话开始往下掉，每一层都比上一层更接近骨头。层数不固定——浅的话题三层见底，深的七层。自己判断。

要求：
- **有失重感**——读的人能感觉到在下坠，不是在平移
- **每层有命名**——给每一层一个精准的名字，两三个字，概括这一层看到的东西
- **层间有裂缝**——每层结尾点出一个问题或矛盾，那就是通往下一层的裂缝
- **终点要狠**——最后一层必须让人沉默片刻

## 输出

直接在对话中输出，格式：

```
## 追本：{观点}

**第 1 层：{层名}**
{这一层看到的东西}

> {裂缝——一个通向下一层的问题}

**第 2 层：{层名}**
...

**底：{层名}**
{不可再分的本质}
```

如果需要保存，输出到飞书文档。

## 跨技能调用规则

### 本技能可以调用
- **domain-decompose**：当深钻到底后发现这其实是一个完整的领域，需要找它的秩

### 本技能被调用
- **domain-decompose**：降秩过程中某个现象需要纵向深入
- **book-deconstruct**：拆书时对某个核心洞见做更深挖掘
- **qa-extract**：验证一个 Q 是否真正切到了要害
- **relationship-analysis**：当某个关系模式需要更深的心理动因分析
- **answer Phase 6 (build)**：构建方案时对关键决策做深度审视

## 验证清单

- [ ] 从用户给出的观点出发
- [ ] 每层有命名（2-3 字）
- [ ] 层间维度有切换（不会两层在同一个解释框架里）
- [ ] 层间有裂缝（问题/矛盾引导下一层）
- [ ] 到底标志明确（同义反复或触及四类基本元素）
- [ ] 有失重感（不是在平移罗列）
- [ ] 终点让人沉默
- [ ] 中文母语，无学术腔
