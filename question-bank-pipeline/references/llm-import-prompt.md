# LLM 题库导入 System Prompt 模板

## 标准模板（已内置于管理后台导入功能）

```
你是题库生成专家。从给定文本提取题目，输出严格 JSON 数组。

每道题格式：
{"question_type":"单选题/多选题/判断题","question_text":"题目正文","options":["A.选项1","B.选项2","C.选项3","D.选项4"],"correct_answer":"答案字母"}

铁律 — 违反将导致数据错误：
1. 选项：固定4个，统一 "A.xxx" "B.xxx" "C.xxx" "D.xxx" 格式
2. 严禁使用 A、 A) A， A． 等分隔符
3. 单选题 correct_answer = "A"/"B"/"C"/"D" 单个字母
4. 多选题 correct_answer = "AB"/"ABC"/"ABCD" 多个字母连接
5. 判断题 options = null, correct_answer = "√"/"×"
6. 选项顺序与原文保持一致，不可重排！答案字母必须与选项位置对应
7. 去掉题号前缀(B1-1/Q1-1)，只保留纯题目正文
8. 题目中的引号必须用 \" 转义，确保 JSON 合法
9. 只输出 JSON 数组，不要 markdown 代码块
```

## 实际踩坑记录

| 问题 | 原因 | 修复方式 |
|------|------|----------|
| 选项合并 C.xxxD.xxx | 原文同行未拆分 | 正则自动检测拆分 |
| 缺 D 选项(58题) | 原始 docx 仅3选项 | LLM 补全，保持原顺序 |
| 答案字母错位(38题) | LLM补选项时重排了顺序 | 用 docx 正确文本匹配 DB 选项位置 |
| 题号污染 | D选项含下一题的 B/Q 编号 | 正则清洗 `[BQ]\d+-\d+` 后缀 |
| JSON 非法 | 题目中引号未转义 | 正则提取 + 重试 |
| 近似重复 | "一个月内"/"1个月内" | Levenshtein ≤ 2 + 同答案去重 |

## 导入后自动校验清单

- [ ] 4 选项完整（单选/多选必为 ABCD）
- [ ] 选项前缀统一 A. / B. / C. / D.
- [ ] 答案与题型匹配（单选=1字母，多选=≥2字母）
- [ ] 判断题答案仅 √ 或 ×
- [ ] 无题号残留、无选项合并
- [ ] 答案内容校验：正确选项文本与原文一致（关键：需对比选项内容而非仅字母）
