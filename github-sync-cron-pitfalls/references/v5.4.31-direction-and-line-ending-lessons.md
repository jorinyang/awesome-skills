## README audit lesson

A broad `### ... (N)` regex reported category sum 108 while all strong inventory surfaces were 112:
- badge: 112
- disk SKILL.md directories: 112
- unique index links: 112
- no disk-only or index-only entries

## Line-ending lesson

Copying local LF files into a codeload-derived Windows worktree caused ordinary `git diff --stat` to show whole-file replacement. `git diff --ignore-space-at-eol --numstat` revealed the semantic delta:
- README: 1 insertion
- sketch: 1 insertion / 1 deletion
- web-spa: 179 insertions / 51 deletions

Use normalized/staged verification for reporting and gates; do not present unnormalized churn as actual content volume.
