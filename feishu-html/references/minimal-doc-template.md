# 极简制度文档模板

适用于：分润制度、定价规则、SOP 等需要"一眼看懂"的内部文档。
触发信号：用户说"简化""太复杂""只保留核心""让人一眼看完能很清晰的理解"。

## 结构模板

```markdown
# {制度名称}

## {核心结构}
一张总览表概括所有分润类别，每行包含：类别名称、比例/公式、归属方。

## {关键比例}
一张表列出所有变量值（如层级比例、税率）。

## 计算公式
逐行公式，自然语言，不配"为什么"解释。每条公式一行。

## {操作规则}
一张表列出所有规则选项和对应参数。

## 举个例
一个完整示例，一张表从开头走到结尾，每步写出中间值。
```

## 格式铁律

- 只允许 h1/h2 两级标题，h3 禁用
- 每个章节开头必须是一张表，表后最多跟一句说明
- 不允许出现连续三段以上纯文字段落
- 金额用 ¥12,345.67，百分比用 15% 不用 0.15
- 变量用中文全称（"合同总额"不是"C"）
